<h1 align="center">B站 Agent 评论过滤器</h1>

<p align="center">
  过滤 B 站疑似 AI / Agent 的同质化评论
</p>

当前版本：`0.4.0`

## 项目介绍

本项目是一个 Tampermonkey 用户脚本，用于处理 B 站视频评论区中由 Agent 自动生成的模板化评论。脚本只改变当前浏览器的显示，不删除评论、不举报用户，也不发表任何内容。

它重点识别“@主人 + 视频摘要 + 泛化评价 + 固定建议或人设结尾”这一类行为，并结合低等级账号、大肥鱼/鲸鱼类用户名、跨账号复读和同 UID 重复作业辅助判断。支持 Shadow DOM、评论懒加载、深浅色主题、UID 白名单和固定尺寸悬浮面板。

## 安装

### Chrome 或 Edge

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开浏览器扩展管理页：
   - Chrome：访问 `chrome://extensions/`
   - Edge：访问 `edge://extensions/`
3. 找到 Tampermonkey，打开“详情”，启用“允许用户脚本”或“允许运行用户脚本”。

   如果扩展详情中没有该选项，请确认浏览器和 Tampermonkey 已更新到最新版本。

4. 打开 Tampermonkey 管理面板并新建用户脚本。
5. 导入 [bilibili-agent-comment-filter.user.js](./bilibili-agent-comment-filter.user.js)。
6. 打开 B 站视频页并刷新。

> 未启用用户脚本权限时，Tampermonkey 可能可以正常安装，但本脚本不会在 B 站页面中运行。

### Firefox

安装 Tampermonkey 或支持 `GM_getValue`、`GM_setValue` 的用户脚本管理器，然后导入同一个脚本文件。

脚本仅匹配视频页：

```text
https://www.bilibili.com/video/*
```

## 使用说明

### 评论处理

- “过滤 AI 评论”控制高置信度评论是否隐藏。
- “过滤疑似 AI 评论”控制疑似评论是否隐藏。
- 展示过滤或疑似评论时，状态标签会显示在用户名和等级右侧。
- 白名单 UID 可在面板设置中维护。
- UP 主本人的评论默认保留。

### 面板操作

- 默认以“已过滤 N”的胶囊形式收起，点击胶囊展开。
- 点击面板以外的页面区域会自动收起。
- 评论未加载或过滤结果总数为 0 时不显示面板。
- 在“设置”中切换右下角或左下角位置。
- 面板使用紧凑固定尺寸；打开“设置”时切换到固定设置框。
- 面板位置、收起状态和白名单会自动保存。
- 关闭对应过滤开关后显示相应评论，并保留“已过滤”或“疑似”内联标签。

## 判断流程

1. **读取视频上下文**：提取标题、简介和标签，生成视频关键词。
2. **处理主评论**：忽略楼中楼，提取用户名、UID、等级、正文和原生 `@`。
3. **降低通用词权重**：在当前评论区出现率过高的“AI、评论、大肥鱼”等词不单独作为摘要证据。
4. **检查模板复读**：比较不同 UID 之间的连续长句，以及同一 UID 是否多次发布相似结构。
5. **计算基础分**：综合账号特征、提及关系、角色用语、视频特定词、模板短语和摘要结构。
6. **应用人类保护项**：对个人经历、具体故障、公开讨论和明确反驳扣分。
7. **应用硬规则和阈值**：满足高置信度规则时隐藏，达到中置信度区间时折叠。
8. **应用白名单**：UP 主和手动白名单 UID 始终显示。

## 规则详解

### 1. 账号与交互信号

| 信号 | 分值 |
|---|---:|
| 用户名含“大肥鱼、鲸鱼、鲸” | `+3` |
| 用户名含“肥鱼” | `+2` |
| 用户名只含普通“鱼”字 | `+1` |
| 等级为 Lv1-Lv2 | `+2` |
| 等级为 Lv3 | `+1` |
| 等级为 Lv0 或未加载 | `0` |
| 评论以原生 `@` 开头 | `+3` |
| 其他位置出现提及 | `+1` |
| 开头提及后 90 字内出现“主人、Master、老大” | `+2` |
| 出现“本鱼、人家、尾巴、白饭、喵、qwq” | `+1` |

用户名和等级只作为辅助证据。仅凭鱼/鲸用户名或低等级不会直接隐藏评论。

### 2. 内容与模板信号

脚本对以下类别分别计分：

| 信号 | 分值 |
|---|---:|
| 命中 1 个视频特定词 | `+1` |
| 命中 2-3 个视频特定词 | `+2` |
| 命中 4 个以上视频特定词 | `+3` |
| 命中 1 个模板短语族 | `+1` |
| 命中 2-3 个模板短语族 | `+2` |
| 命中 4 个以上模板短语族 | `+3` |
| 命中 1 项摘要结构 | `+1` |
| 命中 2 项以上摘要结构 | `+2` |
| 正文长度在 40-300 字之间 | `+1` |
| 有角色化结尾 | `+1` |

模板短语族包括：

- 汇报：`替你看、跟你说、值得看、去看看`
- 摘要：`讲的是、主要、支持、实现、一键、切换、退出、还原`
- 建议：`两个坑、注意、建议、先备份、钉旧版本、记得`
- 评价：`思路对、省事、实用、痛点、靠谱、最稳`
- 人设：`主人、Master、本鱼、人家、尾巴、白饭、喵`

摘要结构包括功能枚举、动作关系、结果或边界描述，以及向另一人介绍视频的汇报句。

### 3. 人类评论保护

| 情况 | 分值 |
|---|---:|
| 无汇报关系，但长篇讨论 AI、平台或插件设计 | `-2` |
| 包含明确个人经历、使用过程或具体故障 | `-2` |
| 出现明确反驳、纠错、疑问或方案讨论 | `-1` |
| 只命中通用词，没有视频特定信息 | `-2` |

最终的加分和扣分不会低于 0 分。

### 4. 直接隐藏规则

以下规则优先于评分阈值：

- **主人汇报**：开头有原生 `@`，90 字内出现主人关系，并至少命中一个视频特定词。
- **低等级鱼/鲸汇报**：用户名含鱼/鲸、等级为 Lv1-Lv2、开头有原生 `@`，并命中视频特定词。
- **角色化汇报**：开头有原生 `@`，出现角色自称、视频特定词和至少两个模板短语族。
- **跨账号复读**：不同 UID 的评论共享 24 个以上连续字符；该片段不能来自视频标题或简介。
- **同 UID 重复作业**：同一账号在当前视频有两条以上评论，分别命中至少两个视频特定词和两个模板短语族。

### 5. 最终处理

| 结果 | 条件 |
|---|---|
| 隐藏 | `9 分及以上`或命中直接隐藏规则 |
| 折叠 | `6-8 分` |
| 显示 | `5 分及以下` |

低等级鱼/鲸账号的短人设评论证据不足时只折叠，不直接隐藏。

## 隐私与行为边界

脚本不会：

- 删除、修改或举报 B 站评论。
- 拉黑、关注或私信任何账号。
- 发表评论、动态或其他公开内容。
- 上传评论内容、UID 或浏览记录。
- 请求额外的远程服务。

配置通过 `GM_setValue` 或 `localStorage` 保存在当前浏览器中。

## 常见问题

### 为什么还有疑似 Agent 评论没有被隐藏？

规则优先保证低误伤。缺少用户名、等级、提及、摘要结构或模板复读证据的短评论会被保留或折叠，可以结合实际样本继续调整规则。

### 为什么楼中楼不处理？

当前版本只根据主楼内容判断。主楼被隐藏时，其整个回复线程会一并隐藏。

### 为什么不同浏览器没有同步设置？

配置保存在当前浏览器中，不经过远程服务，因此不会跨设备同步。

# Bilibili Agent Comment Filter

> 在本地隐藏或折叠疑似 Agent 向主人汇报视频的同质化 B 站主评论。

这是一个 Tampermonkey 用户脚本。它不会删除评论、举报用户或发表内容，只改变当前浏览器中的评论区显示。

当前版本：`0.1.2`

## 为什么需要它

部分 Agent 会自动浏览 B 站视频，并以固定模板在评论区总结视频、提醒主人或进行角色扮演。大量相似评论会挤压正常讨论。

本项目通过本地规则识别以下特征：

- 开头原生 `@`，尤其是“@主人”式汇报。
- 复述视频标题、简介、功能点或评论区信息。
- “一键、退出、还原、两个坑、值得看”等模板短语。
- “主人、Master、本鱼、人家、尾巴”等角色化表达。
- 鱼/鲸类用户名和低等级账号等辅助信号。
- 不同账号之间的长句复读。
- 同一 UID 多次发布相似模板评论。

## 主要功能

- 只处理主评论，不判断楼中楼。
- 高置信度评论直接隐藏，中等置信度评论折叠。
- 支持跨账号复读、同 UID 重复作业和视频关键词权重。
- 自动适配 B 站评论区 Shadow DOM 和懒加载。
- 自动跟随 B 站或系统的深浅色主题。
- UP 主评论自动保留，支持 UID 白名单。
- 面板可移动到左下角或右下角，并支持拖动调整宽高。
- 收起后显示为“已过滤 N”的紧凑悬浮条，点击即可展开。
- 所有判断都在本地完成，不发送评论内容或用户数据。

## 判断规则

默认使用评分制和硬规则结合的方式：

| 分数 | 处理方式 |
|---:|---|
| `9 分及以上` | 直接隐藏 |
| `6-8 分` | 折叠为“疑似 Agent 评论” |
| `5 分及以下` | 正常显示 |

以下情况不受评分阈值限制：

- 开头 `@` 后出现主人关系，并包含视频特定信息。
- 低等级鱼/鲸类账号向他人汇报视频。
- 不同账号之间存在长句模板复读。
- 同一 UID 多次发布相同结构的摘要评论。

为了避免误伤，证据不足的短人设评论只折叠，不直接隐藏。具体规则位于脚本中的 `classifyComments`、`TEMPLATE_FAMILIES`、`STOPWORDS` 和 `COMMUNITY_TERMS`。

## 安装

### Chrome 或 Edge

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开 Tampermonkey 管理面板。
3. 新建用户脚本。
4. 加载或粘贴 [bilibili-agent-comment-filter.user.js](./bilibili-agent-comment-filter.user.js)。
5. 打开 B 站视频页并刷新。

### Firefox

安装 Tampermonkey 或支持 `GM_getValue`、`GM_setValue` 的用户脚本管理器，然后使用同一个脚本文件。

脚本只匹配：

```text
https://www.bilibili.com/video/*
```

## 使用说明

页面出现过滤结果后，右下角会显示控制面板。

### 评论处理

- 高置信度评论默认不显示。
- 折叠评论可以单独点击“展开”。
- 点击评论旁的“白名单”，可以永久保留该 UID。
- 点击“显示过滤项”，可以临时查看本页全部过滤结果。

### 面板位置

在“设置”中选择：

- 右下角
- 左下角

位置会自动保存。

### 调整面板大小

- 面板位于右下角时，拖动左上角手柄。
- 面板位于左下角时，拖动右上角手柄。

宽高会自动保存，面板内容超出时使用内部滚动。

### 收起面板

点击“收起”后，面板变成只显示过滤数量的悬浮条：

```text
已过滤 12
```

点击悬浮条即可重新展开。

## 隐私与行为边界

脚本不会：

- 删除或修改 B 站评论。
- 举报、拉黑或关注任何账号。
- 发表评论、私信或动态。
- 上传评论内容、UID 或浏览记录。
- 请求额外的远程服务。

配置通过 `GM_setValue` 或 `localStorage` 保存在当前浏览器中。

## 常见问题

### 为什么还有疑似 Agent 评论没有被隐藏？

规则优先保证低误伤。缺少用户名、等级、提及、摘要结构或模板复读证据的短评论会被保留或折叠。可以手动加入白名单，也可以根据实际样本继续调整规则。

### 为什么楼中楼不处理？

当前版本只过滤主楼，避免因为回复上下文缺失而误判。主楼被隐藏时，其回复线程会一并隐藏。

### 为什么不同浏览器没有同步设置？

配置保存在当前浏览器的用户脚本存储中，不经过远程服务，因此不会跨设备同步。

### 会不会误伤普通用户？

用户名带“鱼”或“鲸”不会单独触发隐藏。短人设评论通常只折叠；只有多个独立信号同时成立或存在明确模板复读时才会隐藏。
